# 코드 검토와 리팩터링 기록

> 이 문서는 당시 조사·변경의 기록입니다. 현재 구성·지원 범위·호출 경로는 [Architecture](architecture.md), [Integrations](integrations.md), [Validation](validation.md)을 기준으로 합니다.

2026-11-10, 병합된 main `82ce187` 기준입니다. AgentPort 자체 코드의 인증 → API/MCP → 그래프 → 저장소·임대 → 실행 백엔드 → ACP 워커 → 결과 흐름과 대시보드, 배포·초기화 스크립트를 검토했습니다. 재사용 중인 BFF는 세션·CSRF·프록시 연결 경로를 확인했습니다. 상류 UI 전체에 대한 개별 코드 감사나 보안 인증을 의미하지 않습니다.

## 정리한 부분

| 발견한 복잡도 | 변경 |
|---|---|
| README에 기술 스택·검증 이력·개발 명령이 섞여 있음 | 사용자 기능과 실행 예제 중심으로 축약. 문서 목록과 개발 안내를 `docs/`로 이동 |
| 워커의 한 함수가 인증·공급자 검증·프로세스 환경·ACP 대화를 모두 처리 | 같은 모듈 안의 책임별 함수로 분리. 요청 경로에는 검증 → 중복 확인 → 작업 준비 → 실행 → 결과 저장 순서가 보이게 구성 |
| 요청 시 기동과 상시 실행에서 준비 확인·상태 전환 중복 | DB 시작 claim 이후의 실제 기동 경로를 공유. 각 호출자의 예외 처리와 임대 규칙은 유지 |
| 그래프 검증에서 노드 인덱스를 반복 생성 | 호출당 한 번 생성하여 조상 탐색에 재사용 |
| 대시보드 페이지에 독립적인 그래프 편집과 입력 폼이 포함 | `pages/orchestration/GraphEditor.tsx`, `InvokeForm.tsx`로 분리. 공통 타입·표현 헬퍼는 `shared.ts`로 이동 |
| 밀집된 JSX와 폴링 effect의 불명확한 의존성 | 기존 Prettier로 정렬하고, 폴링에서 사용하는 실행 ID를 명시 |

## 유지한 경계

- REST/MCP 계약, 서비스·워크플로우 정의, DB 스키마를 변경하지 않습니다.
- DBOS 데코레이터 함수와 실행 단계 순서를 바꾸지 않습니다. 미완료 외부 작업을 자동 재실행하는 규칙을 추가하지 않습니다.
- 인증·사용자·프로젝트·세션 판정, 비밀 환경 변수 제외, MCP 권한 축소 순서를 유지합니다.
- ContextForge 원본 UI/BFF와 외부 SDK를 자체 구현으로 대체하지 않습니다. 새 의존성을 추가하지 않습니다.
- 새 기능이나 동작 변경을 리팩터링에 섞지 않습니다. 원격 취소, 단절 시 통신 차단 등 기존 제약은 [실행 플랫폼 문서](runtime-platform.md)에 남습니다.

## 검증

기존 테스트를 수정하지 않고 Python 전체·실제 HTTP/MCP·복구·OpenShell SDK 테스트를 실행합니다. 대시보드 화면 테스트·프로덕션 빌드, 변경 파일 ESLint/Prettier, Python Ruff와 문서 링크도 확인합니다. 최종 CI 결과는 PR과 [검증 기록](validation.md)을 참조하세요.
